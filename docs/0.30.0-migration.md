# Migrating to Axle 0.30.0

0.30.0 removes turns from the Agent. An Agent is a *continuation*: it carries
`sessionId` and the active model-facing `messages`, and nothing else. The
transcript — the append-only fold of the event stream — is owned by whoever
consumes the events: attach a `TurnAccumulator` (the shipped in-memory ticker
tape), persist its `state` yourself, and re-seed it on restore. Lose the tape,
lose the transcript; the Agent cannot recreate it.

Compaction is reworked into three layers, each with one job: `triggers` say
*when to ask*, `shouldCompact` says *whether* (a `false` is the only silent
path), and `compact` does *the work* — as ordinary fallible turn work,
streamed like a tool call. The record of a compaction is a `CompactionPart`
that arrives `running`, streams progressive summary text, and settles
`complete` (the message swap applied, atomically) or `error` (a recorded,
non-fatal failure for automatic triggers). Turns can be started or ended by
compaction: the part embeds at the head of a send's turn (`beforeTurn`), at
its tail (`afterTurn`), or in its own engine-opened turn (`manual`).

---

## Breaking changes

### `Agent`

- `agent.history` is gone. The active conversation is `agent.messages`; there
  is no engine-held transcript. For turns, fold the event stream:

  ```ts
  const agent = new Agent(config);
  const tape = new TurnAccumulator();
  agent.on((event) => tape.apply(event));
  // render tape.state.turns; persist tape.state next to agent.snapshot()
  ```

- `agent.compact()` returns `Promise<boolean>` (applied vs. skipped) instead
  of `CompactionRecord | null`.

### `AgentSession`

- Now `{ sessionId, messages }`. The `version`, `archive`, `compactions`,
  `turns`, and `sessionAnnotations` fields are removed, along with the
  constructor's session-version check — unknown keys in stored sessions are
  ignored, so old blobs restore without modification (their extra fields are
  simply dropped). To restore a transcript, seed a `TurnAccumulator` from
  your own persisted copy: `new TurnAccumulator(savedState)`.

### Deleted exports

- `History`, `HistoryInit` — the class dissolved into the Agent's private
  message state.
- `CompactionRecord` — replaced by `CompactionStamp` (see below).

### `TurnEvent`

- `session:restore` deleted. It had no engine emitter; hosts seed their own
  accumulators via the constructor.
- `compaction:start` / `compaction:end` replaced by a part-level lifecycle
  mirroring actions: `part:start` delivers a `running` compaction part into
  its turn, `compaction:delta` streams summary text onto it, and
  `compaction:complete` / `compaction:error` settle it. A compaction
  declined by `shouldCompact` emits nothing at all — there is no skip state
  and no removal rule.

### `CompactionPart`

- `record` removed. The part is self-contained and stateful:
  `{ id, type: "compaction", status: "running" | "complete" | "error",
  summary?, error?, timing? }`. `summary` is the compactor's stamped summary
  text ("what is remembered at the point of forgetting"); a completed part
  without one renders as a bare divider. An `error` part records a failed
  attempt — non-fatal for automatic triggers: the send continued on the
  uncompacted conversation.

### `CompactionConfig` / callbacks

- `CompactionConfig` gains optional `shouldCompact(state, ctx) => boolean` —
  the decision policy, consulted at every trigger boundary including
  `manual` (`ctx.trigger` is the input). Absent = always willing. A `false`
  emits nothing and runs nothing.
- `CompactionCallback` no longer declines: it returns `AxleMessage[]`
  (never `null` — move that logic into `shouldCompact`) and throws on
  failure. Its context loses `lastCompaction` and gains `id` (the
  engine-generated compaction id, shared with the part) and
  `emit(delta: string)` for streaming progressive summary text onto the
  running part.
- `agent.compact()` returns `Promise<boolean>` (applied vs. declined);
  failures reject. Automatic-trigger failures no longer reject the send —
  the errored part is the record.
- To have prior output recognized (no summary-quoting-summary) and the
  summary surfaced on the part, stamp returned messages via metadata:

  ```ts
  {
    role: "user",
    content: summaryText,
    metadata: { axleCompaction: { id: ctx.id, role: "summary" } },
  }
  ```

  See `CompactionStamp` / `getCompactionStamp`. Unstamped output stays valid —
  the part just settles without a summary.

### `PromptCompactor`

- Ships a bound `shouldCompact` alongside `compact` — wire both:
  `setCompaction({ shouldCompact: c.shouldCompact, compact: c.compact,
  triggers })`. The threshold/manual/empty logic lives in `shouldCompact`.
- Streams the summary through `ctx.emit` as it generates.
- Now returns **two** stamped messages — the summary and the recent-user-
  messages appendix — instead of one combined message. Conversations
  compacted by 0.29 restore fine; the carried-over unstamped summary may be
  quoted into the appendix once, on the first post-upgrade compaction.

## Unchanged

- `validateCompactedMessages`, both automatic triggers, threshold/target
  semantics, and the manual `compact()` queueing/cancellation behavior.
- All wire-layer message types; `TurnAccumulator`'s fold API (`apply`,
  `state`, constructor seeding).
