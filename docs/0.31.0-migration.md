# Migrating to Axle 0.31.0

0.31.0 reworks `PromptCompactor`'s sizing contract: size targets move to the
units they can actually be enforced in, and the provider output cap stops
doubling as the size bound.

The Axle CLI is a separate product; its 0.31.0 changes (invocation grammar,
job schema, configuration homes) are recorded in
[packages/axle-cli/CHANGELOG.md](../packages/axle-cli/CHANGELOG.md).

---

## Breaking changes

### `PromptCompactor`

`targetTokens` and `recentUserMessages` are removed; `summaryWords` and
`appendixTokens` replace them:

```ts
// 0.30
new PromptCompactor({
  provider,
  model,
  prompt,
  thresholdTokens: 100_000,
  targetTokens: 30_000,
  recentUserMessages: 10,
});

// 0.31
new PromptCompactor({
  provider,
  model,
  prompt,
  thresholdTokens: 100_000,
  summaryWords: 1_500, // default 1000
  appendixTokens: 15_000, // default: thresholdTokens / 10; 0 disables
});
```

- **`summaryWords`** is a soft bound enforced by escalation: the prompt
  steers the size in words, the result is measured in words, one
  relative-shrink rewrite runs if it lands over ~1.3× the request, and
  word-boundary truncation is the last resort. Anyone depending on the old
  hard "result ≤ targetTokens" guarantee should measure the returned
  messages.
- **`appendixTokens`** budgets the recent-user-message appendix directly
  (up to the last 10 user messages, evicted oldest-first). The message
  _count_ is no longer configurable — a count is a size proxy that fails
  exactly when size matters (one pasted log blows any count).
- **`maxOutputTokens` is no longer the summary budget.** The request now
  carries a generous spend ceiling with thinking headroom. Previously,
  thinking tokens (which share the output cap on every provider) could
  consume the entire budget and fail the compaction with
  `COMPACTION_EMPTY_SUMMARY`; thinking models now summarize reliably.
- **Unset `reasoning` stays unset.** 0.30 coerced it to `false`, which
  OpenAI-compatible wires sent as `reasoning_effort: "none"` — a request
  always-thinking models reject. Pass `reasoning: false` explicitly if you
  relied on forcing thinking off.

### Housekeeping

- The unused `FileStore` type export is removed.
