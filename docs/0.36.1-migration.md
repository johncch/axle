# Migrating to Axle 0.36.1

The Axle CLI is a separate product; its changes are recorded in
[packages/axle-cli/CHANGELOG.md](../packages/axle-cli/CHANGELOG.md).

---

## Breaking changes

### Anthropic documents no longer return citations

Before, every PDF or text document sent to Anthropic asked for citations,
so an answer about it could arrive as several text parts, each with
`citations` whose `source.type` is `"document"`. Axle no longer asks, and
there is no option to turn it back on. The answer arrives as plain text
parts.

Citations from a hosted web search are unaffected on every provider.

A conversation stored by an earlier version can hold answers with document
citations. They stay on the stored messages, and Axle leaves them out of the
requests it sends to Anthropic, which would otherwise reject them.

The reasons are in the File citations section of
[architecture/provider-content.md](./architecture/provider-content.md).
